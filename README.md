# Battery Monitor PRO

Android-приложение: HTML/CSS/JavaScript-интерфейс в WebView, Kotlin-модуль Android BatteryManager и виджет рабочего стола.

## Возможности
- Системный уровень заряда и статус зарядки.
- Тип подключённого питания, температура, напряжение.
- Ток и счётчик заряда, если их предоставляет устройство.
- Оценка времени до разряда или полной зарядки по измеренной скорости изменения уровня.
- Домашний экранный виджет; фоновое обновление WorkManager с минимальным интервалом Android около 15 минут.
- Полностью локальная работа без интернет-разрешения.

## Ограничения
- Время до полного заряда/разряда — оценка, а не гарантия.
- Android не предоставляет универсальный доступ к проценту износа аккумулятора. Системный health status не равен проценту здоровья.
- Некоторые модели не отдают ток или счётчик заряда.
- WorkManager не гарантирует точное время запуска: Android может отложить обновление для экономии энергии.

## Сборка APK без Android Studio
Репозиторий содержит GitHub Actions workflow в `.github/workflows/build-apk.yml`.

1. Откройте вкладку **Actions** репозитория.
2. Если GitHub запросит разрешение на запуск workflows, подтвердите.
3. Дождитесь завершения **Build Android APK**.
4. Откройте успешный запуск и скачайте артефакт **BatteryMonitorPRO-debug-apk** внизу страницы.
5. Распакуйте ZIP артефакта и установите `app-debug.apk` на Android.

Для локальной сборки нужны JDK 17, Gradle 8.9 и Android SDK Platform 35.

## Виджет
После установки удерживайте пустое место на главном экране → Виджеты → Battery Monitor PRO → добавьте виджет.
